# Proyecto II - Taller de Sistemas Embebidos
### Gabriel Pérez Ramírez - Katherine Salazar Martínez - Ronald Duarte Barrantes

En el presente repositorio se  muestran todos los materiales utilizados para la realización del segundo proyecto del curso de Taller de Sistemas Embebidos, de la carrera de Ingeniería Electrónica del Tecnológico de Costa Rica. La disposición del repositorio es la siguiente:
-  **Bitácora:** Se encuentran los archivos correspondientes a las bitácoras de los tres integrantes del grupo.
- **Varios:** Se encuentran carpetas con funciones específicas.
    - **banano-web:** Documentación de la comunicación por el puerto 8080.
    - **Flasheo_Imagen:** Paso a paso de cómo flashear la imagen generada por Yocto.
    - **Imágenes:** Imágenes para probar y evidencias de casos probados.
    - **Primer_Boot:** Paso a paso a seguir cuando se bootea una imagen por primera vez.
- **Yocto:** Todos los archivos necesarios para replicar el ambiente actual de la Jetson.
